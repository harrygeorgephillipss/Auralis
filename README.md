# Auralis

Auralis is an Android-first music player built with Flutter. Its current release is an early, usable local player and catalogue-preview client, not a complete replacement for Spotify or Mochy.

## Current release: 0.4.0

- Local audio import and playback.
- Imported audio is copied into app-private storage; SQLite stores its library metadata.
- iTunes catalogue search and short preview playback (not full-track streaming).
- Android background playback media session and notification controls.
- Five-band Android equalizer through the native Mornye-derived Android audio plugin fork, where supported.
- Android 9+ minimum (API 28), with an adaptive monochrome launcher icon and animated Auralis splash screen.
- In-app LGPL and third-party licence notices under Settings → Open-source licences.

## Important feature limits

- The complete Mornye Rust extension runtime and extension repository/install system are **not integrated**.
- The authorized provider download queue is **not integrated**. The Downloads screen is marked unavailable rather than exposing fake controls.
- Mochy's Kotlin provider modules are **not ported**. Current online discovery uses Apple's public iTunes Search API and only the preview URL it returns.
- Preview URLs must not be treated as downloadable full tracks or lossless audio sources.

## Build and install

See [Android installation](docs/INSTALLATION.md). The reproducible GitHub Actions workflow generates the Android host project, sets minSdk 28 / compileSdk 36 / targetSdk 36, installs the app icon and media-service declarations, runs analysis and tests, and builds a release APK.

## Branding

- Vector logo master: `assets/branding/auralis_mark.svg`
- Animated launch screen: Flutter CustomPainter path animation in `lib/main.dart`
- Android adaptive icon and native launch background: generated by `scripts/prepare_android.py`

## Repository map

- `lib/main.dart` — app UI, audio handler, database, discovery and launch animation.
- `scripts/prepare_android.py` — Android 9+ manifest, service, icon and SDK configuration.
- `upstream/mornye` — pinned upstream source used for the audio service and Android audio plugin packages.
- `THIRD_PARTY_NOTICES.md` — current upstream licence and attribution summary.
- `docs/INSTALLATION.md` — install and first-run guide.
- `docs/SECURITY_AND_LEGAL.md` — security and legal boundaries.
- `docs/PRIVACY_POLICY.md` — current data and network behavior.
- `docs/RELEASE_CHECKLIST.md` — automated and real-device release checks.
