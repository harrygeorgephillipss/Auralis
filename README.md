# Auralis

Auralis is an Android-first, open-source music player project built with Flutter. The project aims to combine a highly customizable, polished listening experience with a modular provider, playback, and download architecture.

<badge>Engineering preview</badge>

**Current state:** Auralis is a tested Flutter UI shell. It is not yet a functional player, streaming client or downloader. The Android host project and upstream playback integration are not yet present in the root app.

## Project goals

- Android-first Flutter application.
- Distinctive, minimal interface with optional glass/translucency effects.
- Customizable themes, player layouts, artwork presentation, and visualizers.
- Local music library and reliable background playback.
- Modular provider/extension system.
- Download manager that only retrieves audio the provider is authorized to supply.
- Preserve real source format and metadata. Never label transcoded lossy audio as lossless.
- Open development, reproducible builds, documented contributions.

## Planned stack

| Layer | Direction |
|---|---|
| UI | Flutter / Dart |
| State | Riverpod (to be integrated after architecture review) |
| Navigation | GoRouter (to be integrated after architecture review) |
| Android playback | Android media session + a maintained Flutter audio integration |
| Persistence | SQLite |
| Native audio / provider operations | Evaluate Mornye's existing Rust crates before reimplementation |
| CI | GitHub Actions |

## Upstream source

Mornye is pinned as a Git submodule at `upstream/mornye` so the reviewed upstream source and its history remain auditable. Clone it with:

```bash
git clone --recurse-submodules https://github.com/harrygeorgephillipss/Auralis.git
```

If already cloned, run `git submodule update --init --recursive`. See [the upstream pin](docs/UPSTREAM_PIN.md) and [Android port checklist](docs/ANDROID_PORT_CHECKLIST.md). The root Auralis app is a starter shell; the Mornye app has not yet been migrated into the root Flutter package.

## Getting started

1. Install Flutter 3.47.8 (matching CI) and Android Studio / Android SDK.
2. Run `flutter doctor` and confirm Android toolchain is available.
3. From this directory run:

   ```bash
   flutter pub get
   flutter run
   ```

4. Connect an Android phone with USB debugging enabled, or use an Android emulator.

## Source inspirations and attribution

Auralis was planned after reviewing user-provided source archives for Mochy Music and Mornye. The initial implementation strategy is to use Mornye's Flutter architecture as the technical base and independently implement the desired UI/UX ideas. No Mochy Kotlin source has been copied into this scaffold.

Before importing any source modules, follow `docs/SOURCE_AUDIT.md` and `docs/SECURITY_AND_LEGAL.md`. Keep all upstream copyright notices and license texts for any code that is later reused.
