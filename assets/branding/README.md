# Auralis brand assets

The app mark is a monochrome, geometric A monogram. The dark square is the launcher background; the white mark remains legible at small sizes.

- `auralis_mark.svg`: editable vector master for the brand mark.
- Android adaptive launcher icon: generated by `scripts/prepare_android.py`.
- Native launch background: generated by the same script.
- Animated Flutter launch screen: implemented in `lib/main.dart` with a stroked-path draw-on animation. It uses the same A mark, fades in, and scales gently before the home screen appears.

The mark is original Auralis artwork and does not use Mochy or Mornye logos.
